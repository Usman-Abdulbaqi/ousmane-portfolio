## 🚀 Deployment

This is a static website and requires no build process.

The recommended workflow is:

```text
GitHub repository
       ↓
   Vercel
       ↓
Live portfolio website
```

Once the GitHub repository is connected to the existing Vercel project, future commits can be deployed through Vercel.

## ✏️ Customization

Most portfolio content can be edited directly in `index.html`.

Visual changes such as colors, spacing, typography, responsive behavior, and theme styling can be adjusted in `styles.css`.

Interactive behavior is handled in `script.js`.
